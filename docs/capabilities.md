# Capability registry

Machine-readable source of truth: `qproof.capabilities.capability_manifest()` and `web/capabilities.json`.

```bash
qproof capabilities
```

Describes **tested** gates, limits, measurement options, verification methods, execution modes, and explicit non-support (hardware, noise, mid-circuit measurement).

Bell / Hadamard / RX(π) / phase fixtures are **examples**, not the capability boundary.
