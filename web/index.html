Overview

QProof verifies falsifiable claims about classical state-vector simulations. The Bell-state experiment is a smoke test and onboarding fixture — not the capability boundary. No quantum advantage or hardware execution is claimed.

Methodology & limitations

      
    
        
  • Backend: classical complex128 state vector (little-endian qubit 0 = LSB).
    • 
        
  • References: analytic closed forms or caller-supplied expected states — not the production gate applicator.
    • 
        
  • Evidence hashes check integrity, not scientific truth.
    • 
        
  • No noise model, mid-circuit measurement, or quantum hardware.
    • 
        
  • QProof is defined by claims it can test and circuits it can support — not by demo count on this page.
    • 
      

      
CLI: pip install -e ".[dev]" && qproof capabilities && qproof run hadamard
