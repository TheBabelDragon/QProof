Overview

QProof runs a classical state-vector simulator in your browser and can load precomputed Python evidence. Bell is a regression fixture, not the capability boundary. No quantum advantage or hardware execution is claimed.

Methodology & limitations

      
    
        
  • Browser backend: classical complex amplitudes, little-endian (qubit 0 = LSB).
    • 
        
  • Python backend remains the independent comparison path for precomputed fixtures.
    • 
        
  • Evidence hashes prove integrity of the hashed body, not scientific truth.
    • 
        
  • Client-side integrity checks are convenience; authoritative verification is qproof verify-evidence.
    • 
        
  • UI-only failure demo only mutates displayed JSON — it is not a verifier test.
    • 
        
  • No noise model, mid-circuit measurement, GPU, or quantum hardware.
