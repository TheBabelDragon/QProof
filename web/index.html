Overview

QProof is a classical state-vector simulator with an independent analytic reference and versioned JSON evidence reports. It demonstrates circuit correctness — not quantum advantage or hardware execution.

Methodology & limitations

      
    
        
  • Simulator: pure-state complex128 state vector, little-endian qubit order.
    • 
        
  • Reference: analytic Bell amplitudes derived independently of the gate engine.
    • 
        
  • Verification rejects incorrect expected values, non-finite amplitudes, and gross shot outliers.
    • 
        
  • Execution mode is always classical simulation — no quantum hardware backend.
    • 
        
  • This interface does not claim quantum advantage or experimental physics results.
    • 
      

      
Reproduce locally: pip install -e ".[dev]" && qproof run bell --shots 1024 --seed 42 --out report.json
